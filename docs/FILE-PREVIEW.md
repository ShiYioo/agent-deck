# 工作区文件查看与改动审阅

入口：任务头部“查看工作区文件”直接打开项目目录树；产出文件名、助手 Markdown 文件链接、工具记录中的文件路径则打开对应文件。文件工作区与对话并排；较窄窗口覆盖工作区，可展开、关闭、调整分栏宽度。只有该任务实际工作区（优先 worktree）内的普通文件可由预览接口读取，路径经过 canonicalize 验证，包含符号链接边界检查。

交互参考 [Zed Project Panel](https://zed.dev/docs/project-panel)：单击临时预览、双击保留标签、关闭标签返回邻近文件、面包屑、自动展开并定位当前文件、方向键导航目录、空格预览与 Enter 保留。目录按需加载，文件夹优先，提供刷新、折叠、已展开目录筛选和任务改动状态。源码使用只读 CodeMirror 文档，支持语法高亮、连续滚动、选取复制、全文查找与行号跳转；切换标签保留源码的阅读位置和选择范围，仅保留轻量位置信息。

## 格式

| 类型 | 展示 |
| --- | --- |
| 文本、代码、JSON、YAML、XML、HTML、SVG、CSV、日志等 | 带片段内行号的文本、搜索、复制；HTML/SVG 不执行 |
| Markdown | 小文档阅读/源码切换；大文档连续源码 |
| PNG/JPEG/GIF/WebP/BMP/ICO/AVIF | 原生图片查看 |
| PDF | 按需加载 PDF.js 与 Worker，逐页绘制、缩放；不执行文档脚本 |
| 音视频 | 原生播放器，仅读取元数据，不自动播放；编码支持取决于 WebView |
| DOCX/PPTX/ODT/ODP | 提取正文/幻灯片文本，不还原完整排版 |
| XLSX/XLSM | 工作表单元格地址、共享文本与缓存值；不重新计算公式或还原格式 |
| ODS | 文档 XML 中的文本值，不还原表格布局 |
| ZIP | 列出条目与大小，不解压 |
| 其他二进制（如旧版 DOC/XLS、RAR、7Z、可执行文件等） | 有界十六进制预览、外部打开 |

所有类型保留“外部打开”和“在文件夹中显示”。损坏、加密、系统不支持的文件如实显示读取错误。

## 性能约束

- 文件面板、PDF 阅读器和 PDF Worker 分别按需加载。
- 普通文本（不超过 4 MiB）作为完整只读文档打开；超过时仅采样 8 KiB，转入后端稀疏行索引模式，不累积前端分页。
- 超大文本按每 512 行记录一个字节位置，缓存最多 4 个文件索引；按视口读取最多 160 行。首次建立索引需要扫描文件一次，但不保留全文；支持 UTF-8、GBK、UTF-16 连续阅读与全局行号跳转。超长物理行保留最多 16 KiB 展示内容。
- 超大文本滚动条映射完整文件（逻辑像素高度超过浏览器可靠范围时做比例映射），不展示“上一段/下一段”。索引按大小和修改时间失效，扫描/读取时变化会提示刷新。超大模式不提供全文查找和语法高亮。
- CodeMirror 根据实际视口渲染，整个文件不限 100 行；语法模块按扩展名动态加载，超过 1 MiB 不启用语法解析。只有当前标签挂载文档；其他标签保留路径和阅读位置，避免标签数增加导致全文常驻。
- 目录只读取用户展开的层级，每次返回 500 个条目，更多条目可继续加载；树使用虚拟行，不递归扫描整个仓库。
- 仍用于 Diff、Office 提取与二进制的轻量行视图每次最多挂载 100 行；这限制 DOM 数量，不限制滚动可访问的总行数。
- UTF-8 分页保留未完整解码字符，UTF-16 保留跨页代理对。非 UTF-8 文本尝试 GBK 解码，显示识别提示。
- Markdown 阅读模式上限 64000 字符，超过后使用连续源码视图。
- 图片、音视频和 PDF 使用仅授权给具体工作区文件的 Tauri asset 协议；不把媒体内容转换成 Base64 跨 IPC 传输。
- PDF 按 64 KiB 区间请求，一次仅绘制一个页面；画布最长边 4096 像素、最多 800 万像素。卸载时取消渲染、销毁文档和 Worker。
- Office/ZIP 压缩文件最多 32 MiB；最多检查 1000 个条目；XML 解压总量最多 2 MiB，正文输出最多 256 KiB。表格每节最多 10000 项，每项最多 4096 字符。
- 产出轮询只采样文件前 8 KiB，不读取完整大文件，也不为每个文件生成补丁。
- 单文件 Git 补丁点击时生成，输出最多 256 KiB，超出时显示截断提示；超过 32 MiB 的当前文件交给外部工具比较。

## Diff 与来源的语义

Diff 展示新旧行号、新增/删除行；新增与删除文件也可审阅。来源展示任务运行器、任务 ID、resolved 模型执行配置；只有 requested 配置时明确标为请求配置，没有模型记录则显示“模型未报告”。运行模式不代替模型名。

目前 Git 补丁来自**当前工作区相对 HEAD**，并非不可变的执行前后快照。界面明确提示这是任务上下文，逐行作者尚未确认。协作指挥方不据此标成作者，历史补丁也不冒充已冻结的版本。精确逐块归属与历史回放需要后续的内容版本及工具写入日志支持。

验证覆盖：Markdown 阅读/源码、脚本不执行、大文本虚拟行和分页、删除补丁行号、resolved 模型标签、PDF 实际渲染与单画布、Office/媒体文件切换，以及 Esc 不停止执行者。Rust 检查工作区边界、UTF-8 分页、UTF-16、二进制和 Office/ZIP 内容提取。
